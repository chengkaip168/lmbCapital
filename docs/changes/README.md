# Change Docs

Records of shipped work, written after a change goes out.

One file per change, named `NNN-short-kebab-title.md`, matching the plan number in
`plans/` where there was one. Empty until the first change ships.

A change doc says what changed, why, and anything a future reader would need to know
that the diff alone does not convey. For decisions that outlive the change itself,
write a record in `docs/tech-decisions/` instead.
